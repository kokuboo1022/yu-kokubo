# WordPress新規案件セットアップ

新規WordPress案件を開始する際の標準手順。
このコマンドを実行すると、要件整理から環境構築までをステップバイステップで進める。

## 実行内容

以下の順序でユーザーにヒアリングし、CLAUDE.mdにプロジェクト情報を追記する。

### STEP 1: 要件ヒアリング

AskUserQuestionで以下を確認する：

1. **クライアント・案件名・納期**
2. **サーバー選定**（CLAUDE.mdのサーバー選定ガイドを提示して相談）
3. **ドメイン**（取得済みか・候補があるか）
4. **テーマ方針**（SWELL / Cocoon / フルスクラッチ）
5. **ページ構成**（資料があればアップロードしてもらう）
6. **デザイン素材**（カンプ・写真・ロゴの有無）
7. **運用体制**（納品後の更新担当者）

### STEP 2: 環境構築チェックリスト

ヒアリング完了後、以下のチェックリストを提示する：

```
[ ] GitHubにprivateリポジトリ作成
[ ] Local by Flywheelで新規サイト作成
[ ] WordPressの日本語化
[ ] SWELLテーマ購入・インストール（または選定テーマ）
[ ] 子テーマ作成・有効化
[ ] 基本プラグイン導入（wp-new-project参照）
[ ] パーマリンク設定（/%postname%/）
[ ] サンプルページ・投稿削除
[ ] ページ骨組み作成（メニュー・固定ページ）
```

### STEP 3: CLAUDE.mdへの記録

プロジェクト情報をCLAUDE.mdの「現在進行中のプロジェクト」セクションに追記する。

### STEP 4: ステージング準備

環境が整ったらステージング構築を提案する。
詳細は `/wp-staging` コマンドを参照。
